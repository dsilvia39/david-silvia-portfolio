# David Silvia Portfolio Starter

A responsive, single-page portfolio foundation inspired by the supplied visual references and tailored to David's product, information systems, ski patrol, and Avalanche Intelligence work.

## Preview

Open `index.html` directly in a browser, or run a local server from this folder:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Before publishing

1. Replace the headshot placeholder in `index.html` with an image.
2. Replace `YOUR_EMAIL@example.com` and the generic LinkedIn URL.
3. Add a PDF résumé and update the résumé button's `href`.
4. Add a live demo or case-study link for Avalanche Intelligence when public access is ready.
